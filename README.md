# SlideFlow

SlideFlow 是下一代智能演示文稿创作框架。它打破了传统 AI PPT 工具中“死板模版强行裁剪内容”的痛点，采用**原子化组件动态排版**与**真实 DOM 渲染逆向导出**的技术，实现内容绝对自由与排版所见即所得。

## 核心架构

本项目由以下几个核心模块组成：

1. **幻灯片抽象语言 (JSON DSL)**
   - 抛弃固定页面模版，提供原子化的排版组件（如：大标题、网格卡片、图文分栏、重点引言等）。
   - Agent 根据输入内容，动态挑选并堆叠组件，生成 `deck.json`。
2. **Web 渲染器与交互式控制台**
   - 纯前端（React + Vite）实现的本地渲染器。
   - 读取 `deck.json`，利用前端丰富的 CSS 特性（圆角、阴影、Flex 排版）完美渲染页面。
   - 提供可视化控制台，支持用户在浏览器中直接修改文字、替换图片。
   - 支持与 Agent 的双向通信，热更新显示 LLM 的修改结果。
3. **所见即所得导出引擎 (DOM to PPTX)**
   - 利用无头浏览器 (Headless Browser) 或本地浏览器计算最终渲染的 DOM 坐标（`getBoundingClientRect`）与样式（`getComputedStyle`）。
   - 将绝对坐标数据喂给 `PptxGenJS` 等生成库，1:1 还原出完全可编辑的本地 `.pptx` 文件，彻底摆脱由于“前后端两套渲染引擎”导致的错位问题。
4. **Agent Workflow (Skill 定制)**
   - 规划生成两步走：先解析文档生成内容大纲（Outline），确认后再分步生成 JSON DSL。

## 开发规划与里程碑

本项目开发分为四个主要阶段：

### 阶段一：定义 DSL 数据结构与基础组件库
- [ ] 制定整个幻灯片的全局配置文件格式（主题色、字体配置）。
- [ ] 设计单页数据结构（`page`）。
- [ ] 梳理并定义核心组件库的数据结构：
  - `Title`: 标题组件
  - `TextBlock`: 段落组件
  - `CardGrid`: 多列卡片组
  - `SplitLayout`: 图文并排版式
  - `ImageBlock`: 纯图片组件

### 阶段二：开发 Web 渲染器 (React + Vite)
- [ ] 初始化 Vite + React + TypeScript 框架。
- [ ] 根据阶段一的 JSON DSL 定义，编写与之对应的 React UI 组件。
- [ ] 开发主界面（播放预览态）与侧边栏（编辑态），支持读取 `deck.json` 并渲染。
- [ ] 实现前端 `contentEditable` 属性或编辑表单，支持手动修改文本并更新 JSON 内存数据。

### 阶段三：开发本地 PPTX 导出引擎
- [ ] 引入 `pptxgenjs` 库。
- [ ] 开发 DOM 解析器脚本，遍历特定 Class 的组件树，提取各节点的绝对坐标、颜色和字号。
- [ ] 编写转换映射逻辑，将前端的绝对像素转换为 PPTX 画布的英寸/磅，输出最终 `.pptx`。

### 阶段四：编写 Agent Skill 与接入测试
- [ ] 编写 Markdown 格式的指令集 (`SKILL.md`)，约束 LLM 如何调用组件库以及拆分大纲。
- [ ] 给定一篇长文档，进行端到端的全流程生成测试。
- [ ] 打包发布。
